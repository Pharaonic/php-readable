# Support

- **Documentation:** [pharaonic.dev/packages/php/readable](https://pharaonic.dev/packages/php/readable).
- **Questions and help:** the [Pharaonic Discord community](https://discord.gg/XQG9RhvEvf).
- **Bugs and feature requests:** [GitHub issues](https://github.com/Pharaonic/php-readable/issues/new/choose), using the issue templates.
- **Security vulnerabilities:** never in public issues; follow [SECURITY.md](SECURITY.md).

When asking for help, include your package version, PHP version, and whether `ext-intl` is installed.
